# 棋譜ビューア（KIF / 分岐つき）

単一ファイル（`index.html`）で動く、静的な将棋棋譜ビューアです。  
KIF/KI2の再生、分岐の多段追従、SFEN入出力、局面URL共有に対応しています。

## 動作方針

- 依存なし（Java不要 / Node不要）
- サーバー不要（静的ホスティングのみ）
- GitHub Pagesでそのまま公開可能
- Notion埋め込みは公開URL（`https://...`）を使えば利用可能

## 主な機能

- KIF読込（ファイル選択 / テキスト貼り付け）
- KI2形式の読み込みフォールバック
- 分岐の多段追従（複数分岐点を連続して辿れる）
- 分岐ツリーUI（到達中ライン上の分岐を手ごとに切替）
- 手順リスト（クリックで移動）
- しおり（登録/解除、一覧ジャンプ）
- 手ごとのメモ（コメント表示/編集）
- 盤面ハイライト（直前の移動元/移動先）
- 指し手アニメーション（軽量）
- キーボード操作（1手/10手、先頭/末尾、Space系）
- 盤面クリック操作（左半分で戻る、右半分で進む）
- 盤面反転（ボタン / `f` キー）
- SFEN読込、局面SFENコピー
- 局面URLコピー（手数・分岐・反転状態を共有）

## 使い方

1. `index.html` をブラウザで開く（ローカル確認）。
2. KIFをファイル選択または貼り付けして `貼付読込`。
3. 再生ボタン、スライダー、手順クリック、キーボードで局面を移動。

## キーボードショートカット

- `←` / `h`: 1手戻る
- `→` / `l`: 1手進む
- `↑`: 10手戻る
- `↓`: 10手進む
- `Home`: 初期局面
- `End`: 最終局面
- `Space`: 1手進む
- `Shift + Space`: 1手戻る
- `f`: 盤面反転

## URLパラメータ

- `kif`: 読み込むKIFのURL
- `ply`: 初期手数
- `branches`: 分岐選択（例: `10:1,22:2`）
- `sfen`: SFENで初期局面を指定
- `flip=1`: 盤面反転で開始
- `css`: 追加CSS URL
- `sq`: マスサイズ（24〜120）
- `fs`: 全体フォント倍率（50〜200）

互換パラメータとして `bply` / `branch` も読み込み対応しています。

## GitHub Pages公開手順（無料）

1. このリポジトリをGitHubへpush
2. GitHubの `Settings > Pages` を開く
3. `Deploy from a branch` を選択
4. ブランチ（例: `main`）と `/ (root)` を指定
5. 発行された `https://...github.io/.../` を利用

## Notion埋め込み

- Notionの `Embed` にGitHub Pagesの公開URLを貼り付け
- `file://` のローカルパスは埋め込み不可
- キーボード操作は埋め込みフレームを一度クリックしてフォーカスすると安定
